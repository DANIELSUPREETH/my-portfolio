# Daniel Supreeth · Personal website

My personal "about me" site: who I am, my education, skills, projects, my GT 650, my hobbies, and the people I spend my time with.

Built with plain HTML, CSS, and JavaScript. No frameworks, no build step, and no dependencies apart from Google Fonts.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

Tip: name the repository `<your-username>.github.io` and the site will live at `https://<your-username>.github.io/`.

## Structure

```
index.html            the whole site (HTML, CSS, and JS in one file)
assets/images/        photos and video posters
assets/videos/        short looping video clips (H.264 MP4)
```

## Editing

- Text, links, and sections are all in `index.html`.
- To swap a photo, replace the file in `assets/images/` with one of the same name (or update the `src` in `index.html`).
- Videos are muted, looping, and only play while on screen, so the page stays light.
